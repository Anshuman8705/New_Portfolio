The brief

What this project explores

Make it easy to move from a topic to a reusable flashcard deck, and let teachers share study material with a class.

Collaboration

My contribution

Originally built collaboratively with Mohammad Ammar, Kamran Ali and Kartik Hande during the Innovo Hackathon at SSGMCE. The application has since been extended with guest study sessions, classroom workflows and a hosted deployment.

Study without leaving the page

Enter a topic to generate a deck, reveal answers and move through the cards on the home page. Saved cards survive refresh and are grouped by topic. A confirmation dialog protects topic deletion; bookmarks, ratings and study scores support review.

Classrooms for teachers and learners

Teachers create an account, create classes, view enrolled learners and share flashcards. Learners join with an eight-character class code and can copy shared cards into their personal study topics. Repeated imports skip cards already copied.

Generation resilience

The Flask backend calls Gemini with bounded retries and a configurable Flash-Lite fallback. Request timeouts limit waiting, and a clear message appears if the provider remains unavailable. Cards are persisted only after a successful, validated response.

Deployment and data

The live application runs on Vercel with hosted PostgreSQL through SQLAlchemy. Signed browser sessions scope personal study data; teacher passwords are hashed. SQLite remains available for local development, and static assets are served from Vercel’s public directory.

Verification

On 4 November 2026, all 51 automated tests passed locally, including retry recovery, fallback, classroom access and topic deletion. Live checks generated 20-card decks and confirmed that a deck remained after refresh. Automated provider tests use mocked responses; availability still depends on Google.

Key workflows

  • Topic-to-flashcard generation without student signup
  • Inline card flipping and saved-topic selection
  • Confirmed deletion of a topic and its cards
  • Teacher accounts and eight-character class codes
  • Shared classroom cards with duplicate-safe imports

Project boundary

AI-generated answers can contain errors and should be checked against course material. Guest decks belong to a browser session; clearing cookies or switching browsers starts a separate session. Generation depends on Google API availability and quota.

The brief

What this project explores

Build a complete demonstration shopping flow, connecting the storefront to catalogue, account and order records.

Application

The project evolved from a static storefront into a React application backed by an Express API and SQLite. Customer and administrator screens share the same catalogue and order records.

Order processing

The server validates checkout data and updates order records and stock within a database transaction. The repository includes API, validation and user-flow tests.

Demo boundaries

This is a learning project, not a real retailer. No actual goods are sold, shipped or charged for. The active app uses USD demo prices and simulated checkout. The legacy India/INR package is separate and unapplied. Hosted SQLite storage requires a persistence plan.

The brief

What this project explores

Bring personal income, expenses and monthly category budgets into one account-scoped application.

Collaboration

My contribution

I co-developed the Expense & Budget Management System with Rahul Paghrut, sharing the project work equally. Our combined work delivered the application's account management, transaction tracking, budgeting and reporting features.

Architecture

Controllers handle web requests, services contain business rules, and Entity Framework Core accesses SQLite. Account-scoped queries use the signed-in user's identity rather than trusting a user ID submitted in a form.

Money calculations

The implementation uses C# decimal values and aggregates amounts in the service layer. This keeps the calculation approach explicit without relying on floating-point SQL sums.

Testing

The public repository includes a smoke-test script covering registration, sign-in, transactions, budget calculations and isolation between users. Its setup and execution instructions are in the README; no current pass count is asserted here.
